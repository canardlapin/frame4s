# Code of Conduct

frame4s follows the
[Typelevel Code of Conduct](https://typelevel.org/code-of-conduct.html) and its
[enforcement procedures](https://typelevel.org/code-of-conduct/enforcement.html).

This adoption does not imply that frame4s is currently a Typelevel affiliate or
organization project.

Until a private project moderation address is published, reports may be made to
the Typelevel Code of Conduct Committee through the contact route documented on
the Typelevel site. Project-specific moderators will be listed here when that
process is established.
